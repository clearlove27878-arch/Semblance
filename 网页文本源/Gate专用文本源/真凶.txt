她变了。

她自己把“始”理解成了提示。

她自己选择了这盘磁带。

[内部交互规则]
==================================================

本 Gate 使用五个固定语义槽位：

1. killer_slot｜真凶
2. medium_slot｜真正承载危险的物品
3. action_slot｜使程岚接触危险的行为习惯
4. wound_slot｜与之对应的身体创口
5. disposal_slot｜凶手怎么处理凶器

每个槽位只能放入一个对象。

五个槽位必须分别正确才正式通过。

本 Gate 不是“四张正确卡片组成一个无序集合”。

同一个对象放入错误槽位，不应判定为正确。

Desktop：

可以支持拖拽对象进入对应槽位。

也必须支持点击对象后选择槽位。

Mobile：

不得依赖拖拽。

必须支持点击人物或线索后，将其加入对应槽位。

所有判定必须基于人物 / 线索的唯一内部 ID。

不要直接使用玩家可见的中文标题字符串作为唯一判定依据。

[反馈判定优先级]
==================================================

一次提交只显示一条主要反馈。

不要同时弹出多条互相冲突的反馈。

判定优先级如下：

1. 五个槽位全部正确
→ Gate通过
→ 显示“五项全部正确”反馈

2. 三个核心槽位正确
→ 显示对应的最具体三项部分正确反馈

3. 两个核心槽位正确
→ 显示对应的最具体两项部分正确反馈

4. 仅真凶槽位正确
→ 显示“人对了”反馈

5. 存在其他单项核心正确内容
→ 可以给予克制的方向性反馈，但不得直接补出其余正确答案

6. 未形成有效正确组合，但包含明确的强错误线索
→ 显示对应“强错误线索反馈”

7. 其他情况
→ 显示“通用错误反馈”

若一次提交同时满足多个反馈条件：

始终选择：

**正确核心项数量最多、与当前提交最具体对应的反馈。**

例如：

玩家同时提交了两个正确核心项和一个“蛇柜”错误项。

优先显示两个正确核心项的部分正确反馈。

不要因为其中包含“蛇柜”而覆盖已经取得的正确进展。
